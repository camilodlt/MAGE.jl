MAGE.jl

MAGE — Multimodal Adaptive Graph Evolution — is a type-aware extension of Cartesian Genetic Programming (CGP) for evolving programs that mix several data types in one graph.

Package name

The Julia package that implements MAGE is still called UTCGP. Renaming it is a separate migration, so throughout this manual the module is UTCGP while the method is MAGE.

using UTCGP

What makes it different

A classic CGP genome is one row of nodes producing one type. A MAGE genome is a UTGenome: one chromosome per type, all reading from the same SharedInput. A node in the float chromosome can connect to a node in the image chromosome, because each connexion carries a TYPE element saying which chromosome it reads from.

That single change buys three things:

  • Type-safe mutation. Bounds are computed so that a mutated connexion is still legal. A program is well-typed by construction, not by trial and error.
  • Multimodality. One evolved program can blur an image, run a Sobel operator, reduce the result to a scalar, and feed that scalar back as the parameter of another image operator.
  • Modularity. Each output has its own chromosome, so adding an output type does not disturb the others.

MAGE has been applied to symbolic regression, program synthesis, image classification, image segmentation and policy search.

A minimal run

using UTCGP

lib          = Library(UTCGP.get_sr_float_bundles())     # what the program may call
ml           = MetaLibrary([lib])                        # one library per chromosome
model_arch   = modelArchitecture([Float64, Float64], [1, 1], [Float64], [Float64], [1])
node_config  = nodeConfig(30, 1, 2, 2)                    # 30 nodes, arity 2, 2 inputs

shared_inputs, ut_genome = make_evolvable_utgenome(model_arch, ml, node_config)
initialize_genome!(ut_genome)
correct_all_nodes!(ut_genome, model_arch, ml, shared_inputs)

The full walkthrough, including the loss function and the search loop, is in Getting Started.

All bundles by output type

These are the bundles exported by the installed package, generated at build time. Each link opens its complete operator list in the catalogue. A factory bundle is specialised on a concrete output type before use. Numeric and generic operators can return different concrete types depending on inputs; the library's caster enforces the chromosome type. Mixed image reductions include integer sizes alongside floating-point statistics. Coordinate and descriptor bundles returning Float64 are grouped with floats, regardless of their name. Bundles named number_*FromImg return scalars, even though their inputs are images.
