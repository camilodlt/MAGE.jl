UTCGP.integer_find.find_first — Function
find_first(from::Vector{<:Number}, what::Number, args...)

Returns the position of the first match between elements in from and what.

If there is no match, it returns 0.

source
julia> find_first([1,2,3], 3)
3
julia> find_first([1,2,3], 10)

Functions

UTCGP.integer_modulo.modulo — Function
modulo(a::Number, b::Number, args...)

Returns a % b, or 0 when b == 0 (like safe_div): an integer modulo by zero would throw and a float one would give NaN, which then spreads through every node that uses it.

source
julia> modulo(10,2)
0
julia> modulo(11,2)
1

Integer-valued predicates.

Bundles

  • bundle_integer_cond

The exhaustive, always-current list of operators in each bundle is on the Bundle Catalogue page.

source

Functions

Predicates return 1 or 0 rather than a Bool, so their result stays in the integer chromosome and can be fed straight to arithmetic or to a multiplexer.

is_eq_to(n::Number, to::Number, args...)
