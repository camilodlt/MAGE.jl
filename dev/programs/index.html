Decoding

Decoding walks back from each output node through its connexions, collecting the nodes it depends on into an ordered list of Operations. Nodes the outputs do not reach are skipped: they are the dormant material a later mutation may reactivate.

UTCGP.Program — Type
Program(ops::Vector{<:AbstractOperation}, ins::SharedInput)
Program(ins::SharedInput)

One decoded output: the ordered list of Operations to run, plus the inputs they read from.

A Program is what a chromosome becomes once its output node has been followed back through the graph — only the active nodes appear, in evaluation order. Supports length, size, indexing and iteration over its operations.

The SharedInput is stored as a similar copy pointing at the original input nodes, so several programs can be evaluated against the same inputs without interfering; replace_shared_inputs! swaps in a new sample.

Produced by default_decoding_callback; one per output node, grouped into an IndividualPrograms. See compile_program for the faster, call-based SequentialProgram view of the same thing.

Two decoders exist. The default one assumes the genome is type-correct — which it is, if it was built with correct_all_nodes! and mutated with standard_mutate! or numbered_mutation!. The free decoder resolves connexions without that assumption, and is what free_mutate! pairs with.

Evaluating

Evaluation runs each operation in order and caches its result on the calling node, so a node feeding several consumers is computed once. Between two samples the values are cleared with reset_genome! and new inputs are installed with replace_shared_inputs!.

Every call goes through a FunctionWrapper, which applies the bundle's caster to the result and substitutes the fallback if the call throws — that is why an evolved program is total and a run never dies on a division by zero.

Compiling

Decoded programs can be lowered into a SequentialProgram: a flat list of steps over temporaries, with no genome objects left in the way. This is both the fast path for repeated evaluation and the readable form of an evolved model.

using UTCGP, Random, Logging
Random.seed!(7)

lib = Library(UTCGP.get_sr_float_bundles()); ml = MetaLibrary([lib])
model_arch = modelArchitecture([Float64, Float64], [1, 1], [Float64], [Float64], [1])
node_config = nodeConfig(12, 1, 2, 2)

shared_inputs, genome = make_evolvable_utgenome(model_arch, ml, node_config)
initialize_genome!(genome)
correct_all_nodes!(genome, model_arch, ml, shared_inputs)

programs = UTCGP.decode_with_output_nodes(genome, ml, model_arch, shared_inputs)
seq = compile_program(programs, model_arch, ml)
print(sequential_source(seq))

UTCGP.append_output_step! — Method
append_output_step!(state, output_index, program)

Second compiler pass: map one decoded output program to an outN alias.

A decoded Program ends with an OutputNode operation. The body pass emits that operation as a normal tmp assignment because output nodes can call real functions. This pass only looks up that already-emitted tmp and gives it the stable public output name.

Running this pass after all body passes preserves the original IndividualPrograms output order while still reusing shared tmp values.

Replay the typed sample prefix, then interpret the failing sample generically, snapshotting typed values before buffers can be reused. Only steps on individual's path are compared. UTCGP.evaluate_population_into! — Method
evaluate_population_into!(outputs, graph, samples;
                          evaluator = nothing, individual_times = nothing, check = false)

Evaluate every individual of graph on every sample.

outputs holds one matrix per program output, outputs[k][individual, sample] being the kth output of individual on sample; for single-output programs a matrix can be passed instead of a one-matrix tuple. Image outputs are copies, so they remain valid after the evaluation.

samples is a vector of input tuples. evaluator defaults to a new one with a fresh pool. individual_times[individual, sample], when given, receives the time of the steps used by that individual (a step shared by several individuals is timed once and counted for each). check = true also runs the generic interpreter and throws if any output differs. On failure it replays the sample prefix and reports the first differing step on the failing individual’s path, including input equality and isolated calls with and without working buffers. Replay cannot recover external mutable state or another task’s random stream; if the failure does not recur, the diagnosis says so explicitly.
