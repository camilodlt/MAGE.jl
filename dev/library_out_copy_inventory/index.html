Allocating image kernels

The following registered operators retain a # out: copy path. They accept out, overwrite it fully, and preserve results, but still allocate their kernel result. Names shared by several bundles are listed once with all those bundles. The six basic 2D morphology operators use genuine ! kernels for matching storage types; their copy path applies to mixed storage. morphogradient_2D and morpholaplace_2D retain copy paths for every storage type.

Direct paths cover 2D arithmetic and scalar arithmetic, constants, identity, inversion, inverse-log and power transforms, RGB arithmetic/channel operations, RGB adjustments/statistics/masking, volume constants/casts, volume arithmetic, Boolean logic, inversion, and gamma. This inventory excludes those paths.
