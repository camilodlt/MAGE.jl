Capitalize Elements

Module

UTCGP.liststring_caps — Module

Case operators broadcast over a Vector{String}.

Bundles

  • bundle_liststring_caps

The exhaustive, always-current list of operators in each bundle is on the Bundle Catalogue page.

source

Functions

UTCGP.liststring_caps.capitalize_list_string — Function
capitalize_list_string(strings::Vector{String}, args...)::Vector{String}

Broadcasts the Base.titlecase function to every element in the vector.

source
julia> capitalize_list_string(["julia", "julia"])
2-element Vector{String}:
 "Julia"
 "Julia"
julia> capitalize_list_string(["julia julia", "julia"])
2-element Vector{String}:
 "Julia Julia"
 "Julia"
UTCGP.liststring_caps.uppercasefirst_list_string — Function
uppercasefirst_list_string(strings::Vector{String}, args...)::Vector{String}

Broadcasts the Base.uppercasefirst function to every element in the vector.

source
julia> uppercasefirst_list_string(["julia julia", "julia"])
2-element Vector{String}:
 "Julia julia"
 "Julia"
