Getting Started

This page builds a complete MAGE run from scratch and explains each object as it appears. The problem is deliberately tiny — rediscover y = x1^2 + 2*x2 from 30 samples — so that the pieces stay visible.

1. Say what the program may compute

A FunctionBundle is a themed group of operators. A Library is the set of bundles available to one chromosome, and a MetaLibrary collects one library per chromosome.

using UTCGP
using Random
Random.seed!(1)

float_bundles = UTCGP.get_sr_float_bundles()
lib = Library(float_bundles)
ml  = MetaLibrary([lib])

length(lib)   # number of callable operators
20

get_sr_float_bundles is one of the premade collections; see Libraries for assembling your own, and the Bundle Catalogue for what each bundle contains.

2. Say what the types are

modelArchitecture declares the inputs, the chromosomes, and the outputs. Here everything is Float64, so there is a single chromosome.

The two extra inputs (1.0 and 2.0) are constants: giving the search a couple of literals to build with is standard practice in CGP.

n_inputs = 4                                  # x1, x2, and two constants

model_arch = modelArchitecture(
    [Float64 for _ in 1:n_inputs],            # input types
    [1 for _ in 1:n_inputs],                  # each input belongs to chromosome 1
    [Float64],                                # one chromosome, of type Float64
    [Float64],                                # one output, of type Float64
    [1],                                      # read from chromosome 1
)
modelArchitecture(DataType[Float64, Float64, Float64, Float64], [1, 1, 1, 1], DataType[Float64], DataType[Float64], [1])

3. Say how big the graph is

nodeConfig fixes the shape of every chromosome. offset_by must equal the number of inputs.

node_config = nodeConfig(
    20,        # nodes per chromosome
    1,         # connection temperature
    2,         # arity: at most 2 arguments per node
    n_inputs,  # inputs sitting in front of the chromosome
)
nodeConfig(20, 1, 2, 4)

4. Build the genome

make_evolvable_utgenome returns the SharedInput — the input nodes every chromosome reads — and an uninitialised UTGenome. Initialising fills the integers at random; correct_all_nodes! then repairs any node whose connexions do not match the type its function expects.

shared_inputs, ut_genome = make_evolvable_utgenome(model_arch, ml, node_config)
initialize_genome!(ut_genome)
correct_all_nodes!(ut_genome, model_arch, ml, shared_inputs)

length(ut_genome)          # chromosomes
1

At this point ut_genome is a valid random program. See Genome and Nodes for what the integers mean.

5. Say what "good" means

A problem is stated as a BatchEndpoint: a struct whose constructor receives every individual's outputs and the expected value, and stores one score per individual. Lower is better.

struct EndpointMAE <: UTCGP.BatchEndpoint
    fitness_results::Vector{Float64}
    function EndpointMAE(preds::Vector{<:Vector{<:Number}}, y::Number)
        res = Float64[]
        for ind_outputs in preds
            p = ind_outputs[1]
            push!(res, isnan(p) ? 1e6 : abs(p - y))
        end
        return new(res)
    end
end

Ready-made endpoints for the standard PSB2 error functions are EndpointBatchAbsDifference, EndpointBatchLevensthein and EndpointBatchVecDiff.

6. The data

Each row of X is the vector of values for the input nodes, in order — the two variables followed by the two constants.

target(x1, x2) = x1^2 + 2 * x2

raw = [(round(rand() * 4 - 2; digits = 3), round(rand() * 4 - 2; digits = 3)) for _ in 1:30]
X = [Any[x1, x2, 1.0, 2.0] for (x1, x2) in raw]
Y = [target(x1, x2) for (x1, x2) in raw]

X[1], Y[1]
(Any[0.879, -0.987, 1.0, 2.0], -1.201359)

7. Run the search

runConf configures a 1 + λ search, and fit runs it. The long argument list is the callback pipeline: one tuple per phase of a generation. See Fitters and Callbacks.

using Logging

run_conf = runConf(
    6,     # lambda: offspring per generation
    30,    # generations
    1.1,   # mutation rate (here: one active node per individual)
    0.1,   # output mutation rate
)

best_genome, best_program, history = with_logger(NullLogger()) do
    fit(
        X, Y, shared_inputs, ut_genome, model_arch, node_config, run_conf, ml,
        nothing,                                             # pre callbacks
        (:default_population_callback,),                     # build the population
        (:default_numbered_new_material_mutation_callback,), # mutate
        (:default_ouptut_mutation_callback,),                # mutate the outputs
        (:default_decoding_callback,),                       # genome -> programs
        EndpointMAE,                                         # fitness
        nothing,                                             # after each batch
        (:default_elite_selection_callback,),                # pick the survivor
        nothing,                                             # after each generation
        (:default_early_stop_callback,),                     # stop at loss 0
        nothing,                                             # after the loop
    )
end

8. Read the result

The winning genome is best_genome, and best_program is its decoded Program per output. To read the evolved program, compile it and render its source — only the active path appears:

seq = compile_program(best_program, model_arch, ml)
print(sequential_source(seq))
function sequential_program(x1, x2, x3, x4)
    tmp1 = safe_call(identity_float, x4; return_type=Float64)
    tmp2 = safe_call(experimental_is_lt, x1, x3; return_type=Float64)
    tmp3 = safe_call(number_minus, tmp2, x1; return_type=Float64)
    tmp4 = safe_call(power_of, x2, tmp3; return_type=Float64)
    tmp5 = safe_call(number_mult, tmp4, tmp1; return_type=Float64)
    tmp6 = safe_call(identity_float, tmp5; return_type=Float64)
    out1 = tmp6
    return (out1,)
end

The compiled SequentialProgram is also callable, which is how an evolved model is deployed:

seq(1.0, 2.0, 1.0, 2.0)
(1.0,)
